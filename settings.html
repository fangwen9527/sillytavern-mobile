1 把服务端组件装进 plugins/ 待处理
酒馆自带的「安装扩展」只能装前端扩展（public/scripts/extensions/third-party）。 真正干活的网关和 iroh 隧道是 服务端插件，必须落在酒馆根目录的 plugins/ 里，而酒馆没有任何 UI 入口能把文件放进那里。 下面的命令会自动完成：定位酒馆目录 → 备份旧版本 → 复制 → npm install。
操作：打开酒馆根目录（有 server.js 的那个文件夹）→ 在空白处 Shift + 右键 → 在此处打开 PowerShell → 粘贴对应命令回车。
Windows PowerShell
powershell -ExecutionPolicy Bypass -File ".\public\scripts\extensions\third-party\sillytavern-mobile\install.ps1"
复制 PowerShell 命令
Windows CMD / 命令提示符
powershell -NoProfile -ExecutionPolicy Bypass -File ".\public\scripts\extensions\third-party\sillytavern-mobile\install.ps1"
复制 CMD 命令
Linux / macOS / Termux
node "public/scripts/extensions/third-party/sillytavern-mobile/install.mjs"
复制 Linux/macOS 命令
完成后应该看到 完成。请重启 SillyTavern。；面板标题右侧的状态会变成「运行中」。
2 确认 config.yaml 打开了服务端插件 待确认
酒馆根目录的 config.yaml 里必须有这一行（默认就是 true，如果你改过就检查一下）： 
enableServerPlugins: true
这一项关掉时，plugins/ 下的所有服务端插件都不会被加载（包括这个）。改完要重启酒馆。
3 重启酒馆 待重启
装完组件或改过 config.yaml 之后，重启酒馆才会加载服务端插件。
Windows
:: 在运行酒馆的窗口按 Ctrl+C 停止，然后
node server.js
复制启动命令
Linux / macOS
# 在运行酒馆的窗口按 Ctrl+C 停止，然后
node server.js
复制启动命令
重启后刷新本页面，状态徽章变成「运行中」即成功。
